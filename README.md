# Card War Game

A simple solitaire war game that plays in your browser, built with React and Vite.

## Features

- Classic card game mechanics
- Interactive war scenario with step-by-step card drawing
- Visual card display with animations
- Sound effects for different game events

## How to Play

1. Click on your deck to draw a card
2. The player with the higher card value wins the round and collects both cards
3. If there's a tie, the "war" begins:
   - The tied cards remain on the table
   - Draw three additional cards one at a time
   - The player with the higher value on the final card wins all cards in play

## Technologies Used

- React
- Vite
- Tailwind CSS
- Framer Motion for animations

## Installation

```bash

# Make sure you are on desketop
cd ~\Desktop

# Clone the repository
git clone https://github.com/UX-ZERO/Simple-solitaire-war.git

# Navigate to the project directory
cd Simple-solitaire-war

# Install dependencies
npm install

# Start the development server
npm run dev
```

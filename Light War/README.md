# Card War Game

A simple card game implementation of "War" built with React and Vite.

## Features

- Classic War card game mechanics
- Interactive war scenario with step-by-step card drawing
- Visual card display with animations
- Sound effects for different game events

## How to Play

1. Click on your deck to draw a card
2. The player with the higher card value wins the round and collects both cards
3. If there's a tie, a "war" begins:
   - The tied cards remain on the table
   - Draw three additional cards one at a time
   - The player with the higher value on the final card wins all cards in play

## Technologies Used

- React
- Vite
- Tailwind CSS
- Framer Motion for animations

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/CardWar.git

# Navigate to the project directory
cd CardWar

# Install dependencies
npm install

# Start the development server
npm run dev
```
